# 🦀 Mini Redis (Rust - CodeCrafters)

A toy Redis clone built in Rust (for the CodeCrafters "Build Your Own Redis" challenge).

---

## 🚀 Features

- TCP server using Tokio

- RESP protocol parsing

- Commands: `PING`, `ECHO`, `SET`, `GET`

- TTL support (`EX`, `PX`)

- Concurrent clients (async + tasks)

- In-memory storage (`HashMap`)
